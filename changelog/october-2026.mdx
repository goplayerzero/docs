## Scheduled Workflows

Automations start a workflow on a schedule, or when something happens: a Git event in a connected repository, a ticket event in a connected ticketing tool, or a custom event your own system sends. A plain-language condition can limit which events start a run, and events can be collected into one run by count or by time. Automations live in Organization Settings and replace the Triggers and Monitors settings. Existing API trigger endpoints are available as custom event sources.

Recurring checks and event-driven work start without anyone opening a thread, and every way a workflow can start is set up in one place.

## Choose Your Model

The message box has a model picker. "Auto" picks a model and effort level for each message, optimizing for Intelligence, Balance or Cost, or you can choose a specific model. On the Models settings page, admins turn models on or off for the Economy, Standard and Pro classes and can add the organization's own Anthropic or OpenAI key.

Teams can match the model to the task in front of them, and admins decide which models are in use and whose key pays for them.

---

## Manage Business Groups and Their Models

Org owners can set which model classes each Business Group may use in chat. Once PlayerZero turns on group editing for the organization, owners can also create, rename, describe, archive and restore groups from the Business Groups settings page.

Model access and cost can follow how the organization is structured.

---

## Import Files from Salesforce Cases

Agents can import the files linked directly to a Salesforce case, under the same attachment setting as the other ticketing integrations.

Investigations of Salesforce cases work from the logs and screenshots customers attach, not only from the case text.

---

## Import Ticket Archives and Linear Attachments

ZIP, tar and other archive files are now included when PlayerZero imports a ticket's attachments, and the agent unpacks them in its sandbox. Linear attachment import now works.

Log bundles that customers attach as archives reach the investigation instead of being skipped.
