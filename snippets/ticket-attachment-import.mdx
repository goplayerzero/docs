PlayerZero can read the images and documents attached to a ticket, so an investigation works from the screenshots, logs, and files the ticket already carries instead of its text alone.

Whether attachment import is on by default depends on when the integration was connected. Integrations connected on or after June 26, 2026 import attachments by default. Integrations connected before that date do not.

To update it, open the integration's settings, find the project, and under **Ticket Attachment Settings** set **Mode** to **Allow Attachments**. Choose **Do Not Allow** to stop importing. Only Project Owners may update this setting.

<Note>
The setting appears only when the integration is connected to that project.
</Note>
